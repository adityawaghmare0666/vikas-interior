QUICK DEPLOYMENT
1. Extract this ZIP.
2. Upload the extracted files to your hosting service. The root index.html must be at the top level of the published folder.
3. The root index.html includes all images and fonts. No installation, build command, server, database or API key is needed.

NETLIFY
Drop the extracted website folder into Netlify's manual deployment page. The folder should contain index.html directly.

GITHUB PAGES
Upload the extracted files to a GitHub repository. In Settings > Pages, select Deploy from a branch, choose main and / (root), then save. If you use GitHub Actions instead, the included .github/workflows/static.yml publishes the repository root.

OTHER STATIC HOSTS / CPANEL
Upload index.html to your host's web root (often public_html). You can also upload the entire extracted folder contents.
